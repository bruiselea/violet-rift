# Violet Rift 導入ガイド

このパックは Obsidian 用のダークテーマと、独立した英字表示用フォントです。
プレビュー版 0.2.0。対応下限は検証対象の Obsidian 1.14.4 に設定しています。
ライトモード専用デザインは含まず、ライトモードでは標準表示になります。

## テーマ

1. Obsidian の「設定 → 外観」で現在のテーマ名と有効なCSSスニペットを控えます。
2. 「テーマフォルダを開く」から、Vault の `.obsidian/themes/` を開きます。
3. `Theme/Violet Rift/` フォルダを、フォルダごと `.obsidian/themes/` にコピーします。
   完成形は `.obsidian/themes/Violet Rift/theme.css` と `manifest.json` です。
4. 外観設定を開き直し、「テーマ」で **Violet Rift** を選び、「配色」を **ダーク** にします。
5. 以前の `crying-obsidian` スニペットを使っている場合はオフにします。他の外観CSSも競合する場合があります。
6. メニューもテーマに揃える場合は「設定 → インターフェース → ネイティブメニュー」をオフにします。オンのままではmacOS側のメニュー表示になります。

テーマはCSSのみです。ノート本文・リンク・プラグインの設定は変更しません。
ゲーム素材、外部フォント、外部画像のダウンロードは行いません。

## フォントを追加したいときだけ

フォントはテーマの有効化だけでは適用されません。次のどちらかを選びます。

- **Obsidianだけ:** `Optional CSS/rift-pixel-display.css` を `.obsidian/snippets/` にコピーし、
  「設定 → 外観 → CSSスニペット」の更新ボタンを押して有効にします。
  英字UIと見出し1・2に使用し、本文の既存フォントは維持します。
  日本語は既存の日本語フォントにフォールバックします。
- **デザインソフトなど:** `Fonts/RiftPixel-Regular.ttf` をOSの通常のフォント管理からインストールします。
  インストール後、アプリのフォント一覧で **Rift Pixel** を選びます。

英字112文字、Regular 1書体のみ。日本語・アクセント付きラテン文字は未収録です。
見出しや短いラベル向けです。コードエディタや長文用の完成書体ではありません。
10pxの倍数は設計グリッドに合いやすく、それ以外は環境によって輪郭が滑らかになります。

## オプション

`Optional CSS/` から欲しいファイルだけ `.obsidian/snippets/` にコピーして有効にします。

- `violet-rift-still.css`: 流れるしずくのアニメーションを停止。模様は残します。
- `violet-rift-quiet.css`: しずくと背景模様を非表示。配色と角形のUIは残します。
- `violet-rift-wake.css`: Wake Dashboard 用の追加スタイル。プラグイン本体は付属しません。

OSの「視差効果を減らす／アニメーションを減らす」にも追従します。

## 戻し方と不具合時

テーマを元のテーマまたは Default に戻し、このパックのCSSスニペットをオフにします。
完全に削除する場合は、追加したテーマフォルダとスニペットだけを削除します。
OSにインストールしたフォントはOSのフォント管理から削除できます。

一覧に出ないときはフォルダが二重になっていないか確認し、設定を開き直してください。
他のテーマや外観スニペットとの併用、プラグイン独自画面は表示を保証していません。
モバイル・Windows・Linuxでの実機検証は未完了です。
